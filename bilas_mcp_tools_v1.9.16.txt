INSTALLATION
================================================================================

pip install git+https://github.com/elony-7/Bilas.id-MCP-Server.git@v1.9.16
playwright install

CLI: bilas-mcp [--token <JWT>] [--outlet <ID>] [--remote-bridge] [--help]
State file: ~/.bilas_id/token_state.json
Persistent dashboard profile: ~/.bilas_id/dashboard_browser_profile
